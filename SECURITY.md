# Security policy

Vex is an alpha interpreter and is not suitable for processing untrusted
programs in a privileged environment. The `0.1.0-alpha.1` release line is
supported on a best-effort basis.

Please report suspected security issues privately to
cybercore.sh@gmail.com rather than opening a public issue with exploit details.
Include the affected version, reproduction steps, and impact. Response and
disclosure timelines are handled on a best-effort basis.
