# Vex

Vex is an experimental Rust-based language prototype. The current release is
an alpha interpreter for a deliberately small language.

The project roadmap is in [Milestones](milestones.md). The
[language reference](language.md), [CLI reference](cli.md), and
[diagnostics guide](diagnostics.md) document the user-facing contracts. The
first milestone defines the quality gates that every change must pass before
the language grows further.
